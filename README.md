# Class 5 / Class 6 Landau-Lifshitz Lax correspondence

Reproducible calculations, machine-learning search records, research notes, and the manuscript source for the Class 5 / Class 6 quantum-to-classical Lax correspondence project.

The repository separates the **final analytic checks** from the **discovery path**. Machine learning was used to select coefficients and local structures inside finite symmetry-informed libraries; the final claims are checked independently by symbolic identities, finite-lattice calculations, Hamiltonian equations of motion, and (for Class 5) a classical `r`-matrix / monodromy construction.

## Repository layout

- `paper/` — current manuscript source and the CI-built `paper/main.pdf`.
- `notes/` — self-contained Japanese research-note source, including the full research history and ML search record, together with the CI-built `notes/full_research_note_ja.pdf`.
- `scripts/class5/` — Class 5 symbolic, finite-spacing, and classical `r`-matrix checks.
- `scripts/class6/` — Class 6 symbolic and finite-spacing checks.
- `scripts/ml/` — original Class 5 and Class 6 coefficient searches adapted to the manuscript conventions, with executable checks against the archived originals.
- `results/` — machine-readable outputs generated by the verification scripts.
- `archive/` — provenance/index information for independent derivation reports produced before the unified manuscript/note.
- `REPRODUCIBILITY.md` — map from calculations/claims to commands and output files.
- `PROJECT_STATUS.md` — current physics conclusions, manuscript status, and open decisions.
- `AGENTS.md` — notation, LaTeX, and verification conventions for future work on this repository.

## Quick start

Python 3.11 is the CI reference version.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements-ml.txt
make verify
```

The full verification target runs:

```text
Class 5 exact symbolic checks
Class 5 finite-spacing and finite-lattice checks
Class 5 classical r-matrix / monodromy comparison
Class 6 exact symbolic checks
Class 6 finite-spacing and off-shell checks
Original-code convention and loss/gradient checks
Class 5 original 12-feature ML coefficient search
Class 6 original-derived ML coefficient search with equivalent off-shell loss
```

Build the manuscript and the complete research note with

```bash
make paper
make note
```

The Japanese note requires LuaLaTeX, `luatexja`, and Harano Aji fonts. GitHub Actions installs the corresponding TeX Live packages before building it.

## Reproducibility status

The Class 5/6 coherent-symbol and finite-lattice scripts in `scripts/class5/` and `scripts/class6/` are the independent verification programs used for the final checks. The original historical ML scripts have now been recovered and are preserved byte-for-byte in `archive/ml_original/`. The active versions in `scripts/ml/` express those searches in the manuscript spin, time, coupling and spectral-parameter conventions. They preserve the original candidate spaces, sampling distributions, losses and Adam/L-BFGS settings. An executable comparison checks the loss and parameter gradients for arbitrary coefficients and the exact agreement of the recovered matrices with the manuscript.

Class 5 trains thirteen real coefficients with an off-shell residual and a uniform sparsity penalty. Class 6 trains eight real coefficients; its default off-shell residual is exactly equivalent to the original on-shell curvature objective for this ansatz. Use `--training-mode on-shell` to select the original formulation. Both analytic Lax certificates are verified off shell. New results are written under `results/ml/class5/` and `results/ml/class6/`, with the original on-shell rerun in `results/ml/class6_onshell/`; historical aggregate metrics remain in `results/ml/historical_summary.json`. Outputs of the superseded least-squares reconstructions are retained in `archive/ml_reconstructed/`. See [the reproducibility guide](REPRODUCIBILITY.md#machine-learning-discovery-path) for the convention dictionary and numerical protocol.

## Continuous integration

`.github/workflows/ci.yml` runs the complete Python verification suite and compiles both LaTeX documents on every push and pull request to `main`. The PDFs are uploaded as workflow artifacts. After all verification and build jobs succeed on a push to `main`, CI also updates the tracked files

- `paper/main.pdf`
- `notes/full_research_note_ja.pdf`

in a `[skip ci]` bot commit. Thus the PDFs in the repository are reproducible build products of the committed sources.

For pull-request reviews, use the PDFs in the current CI run's `compiled-documents` artifact; the tracked PDFs on the working branch are not automatically updated. During ChatGPT-assisted manuscript reviews, the affected PDFs are also delivered as files in the active session's Library before review, with the source commit and CI run identified. See [the PDF review workflow](AGENTS.md#pdf-review-and-publication).

# Contributing

This repository accompanies an active research project. Small corrections,
reproducibility fixes, and convention/notation issues are welcome through
pull requests or issues.

For changes to physics formulas, please include at least one of:

- an analytic derivation,
- a failing/passing symbolic check,
- a finite-lattice numerical counterexample or verification,
- a precise literature reference identifying the convention or formula.

Generated LaTeX auxiliary files should not be committed. Updated manuscript or
research-note PDFs may be committed together with their source when the source
changes materially, but CI artifacts are the default compiled outputs.

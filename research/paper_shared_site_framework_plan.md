# Manuscript restructuring around the local time-Lax continuum limit

Date: 2026-09-14.

This note records the scope of branch `paper/shared-site-framework`.  The
branch is stacked on `research/shared-site-generalization` and is intended to
change the manuscript framing only after the analytic generalization and its
research-note checks have passed.

The manuscript changes on this branch are limited to:

1. stating the known continuum-Lax and quantum time-Lax constructions before
   defining the local finite-lattice-to-continuum question;
2. adding the conditional spin-1/2 shared-site identity to the common setup;
3. treating Class 5 and Class 6 as model realizations and independent checks of
   that identity;
4. correcting the interpretation of the Class 6 second spatial coefficient:
   it is retained in intermediate products and provides a model-specific
   representation of the second moment, but is not independent data in the
   general formula;
5. adding the exact Class 6 dictionary to the known rational eleven-vertex
   Landau-Lifshitz pair;
6. updating the Abstract, Introduction, comparison and Summary accordingly.

The separate branch `research/class5-generic-lax-comparison` existed when this
branch was created and pointed to the same pre-paper commit.  This branch does
not alter the Class 5 generic-Lax comparison or attempt to replace work being
done there.  If that branch later changes manuscript files that overlap with
this branch, the physics results should be reconciled before either paper
branch is merged.

The manuscript does not claim a new coherent-state symbol calculus, a new
quantum time-Lax hierarchy, a new Class 6 hierarchy, arbitrary physical spin,
higher Hamiltonian flows, or finite-time quantum convergence.
